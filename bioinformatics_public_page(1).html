GC Content Calculator

Computes the GC percentage of a DNA sequence

seq = "ATGCGATCGTACG"
gc_content = (seq.count('G') + seq.count('C')) / len(seq) * 100
print(f'GC Content: {gc_content:.2f}%')

DNA Complement

comp_dna = "".join(complement[base] for base in dna)

Reverse Complement

Returns the reverse complement of a DNA sequence

dna = "ATGCGT"

rev_comp = "".join(complement[base] for base in reversed(dna))

Hamming Distance

Counts the differences between two aligned sequences

seq1 = "GAGCCTACTAACGGGAT"
seq2 = "CATCGTAATGACGGCCT"
distance = sum(1 for a, b in zip(seq1, seq2) if a != b)
print(f'Hamming Distance: {distance}')

Sound Speed in Seawater

Computes sound speed (m/s) using the Mackenzie equation

T = 10   # Temperature °C
S = 35   # Salinity PSU
speed = 1449.2 + 4.6*T - 0.055*T**2 + 0.00029*T**3 + (1.34 - 0.01*T)*(S - 35)
print(f'Sound Speed: {speed:.1f} m/s')

Light Attenuation

Calculates remaining light at depth (Beer–Lambert law)

import math
I0 = 1000        # Surface light
k = 0.15         # Extinction coefficient
depth = 15
I = I0 * math.exp(-k * depth)
print(f'Light Intensity: {I:.2f}')

Shannon Diversity

Computes the Shannon diversity index for species counts

import math
species_counts = [12, 8, 5, 20, 3]
total = sum(species_counts)
shannon = -sum((c/total) * math.log(c/total) for c in species_counts)
print(f'Shannon Index: {shannon:.3f}')
